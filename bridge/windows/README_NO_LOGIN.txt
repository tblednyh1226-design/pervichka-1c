Помогатор / MAIN без логина и пароля.
1. Распакуйте все файлы архива, не запускайте из 7-Zip.
2. На компьютере MAIN запустите INSTALL_MAIN_NO_LOGIN.cmd.
3. Установщик покажет код из 32 символов и скопирует его в буфер обмена.
4. В браузере откройте Помогатор → Производство → iiko → Подключить MAIN. Вставьте код.
5. Далее нажмите Получить план с MAIN.

MAIN получает запрос, считывает исходный Excel и передаёт его по HTTPS.
Файл не изменяет. В iiko документы НЕ создаёт. Расписания 09:00 нет.
После установки фоновой модуль запускается с Windows автоматически.
Возможна проверка через CHECK_MAIN_NO_LOGIN.cmd.
Код доступа не публикуйте. Хранится в привязке браузера и зашифрованном файле MAIN.
Старый модуль с логином не требуется. Если он был установлен, уберите его из автозагрузки Windows.
