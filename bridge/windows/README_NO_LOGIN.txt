Помогатор / MAIN без логина и пароля.
1. Распакуйте все файлы архива, не запускайте из 7-Zip.
2. На компьютере MAIN запустите INSTALL_MAIN_NO_LOGIN.cmd.
3. Установщик покажет код из 32 символов и скопирует его в буфер обмена.
4. В браузере откройте Помогатор → Производство → iiko → Подключить MAIN. Вставьте код.
5. Далее нажмите Получить план с MAIN.

MAIN получает запрос, считывает исходный Excel и передаёт его по HTTPS.
Файл не изменяет. В iiko документы НЕ создаёт. Расписания 09:00 нет.
После установки фоновой модуль запускается с Windows автоматически.
Возможна проверка через CHECK_MAIN_NO_LOGIN.cmd.
Код доступа не публикуйте. Хранится в привязке браузера и зашифрованном файле MAIN.
Старый модуль с логином не требуется. Если он был установлен, уберите его из автозагрузки Windows.

=== ОТКРЫТЫЙ EXCEL / ОБНОВЛЕНИЕ MAIN ===
Начиная с версии 2026.11.01-open-excel-v2 MAIN может читать сохранённый XLSX,
даже если книга открыта в Excel для редактирования (без блокировки на запись).
После нажатия «Сохранить» в Excel последующие запросы получают новую версию.
НЕСОХРАНЁННЫЕ изменения из открытой Excel-книги получить невозможно.
Если Excel сохраняет файл именно в момент запроса, MAIN повторит чтение
до 8 раз и проверит целостность XLSX, не отправляя неполный файл.
Если программа удерживает файл с исключительной блокировкой на чтение,
MAIN сообщит об ошибке; обойти такую блокировку обычным чтением нельзя.

КАК ОБНОВИТЬ УЖЕ РАБОТАЮЩИЙ MAIN (без смены кода):
1. Выполнить на том же компьютере MAIN, под тем же пользователем Windows,
   что устанавливал Помогатор. Excel закрывать не требуется.
2. Распаковать архив в отдельную папку (не запускать из архива).
3. Запустить UPDATE_MAIN_NO_LOGIN.cmd (не INSTALL_MAIN_NO_LOGIN.cmd).
4. Дождаться сообщения «Модуль MAIN обновлён ...».
5. При необходимости проверить через CHECK_MAIN_NO_LOGIN.cmd.
6. Открыть файл Excel, сохранить изменения, нажать «Получить план с MAIN».
Привязка и 32-символьный код сохраняются в конфигурации MAIN.
Журнал проверки: %LOCALAPPDATA%\PomogatorMAINGuest\agent.log
