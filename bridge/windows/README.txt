Помогатор — MAIN. Без Python и без установки Excel-драйверов.

1. В браузерном Помогаторе откройте Производство → iiko и нажмите «Код подключения MAIN».
2. Распакуйте ВСЕ файлы из ZIP в обычную папку Windows (не запускать внутри 7-Zip).
3. На компьютере MAIN дважды нажмите INSTALL_MAIN.cmd, введите 12-символьный код.
4. Программа копирует себя в %LOCALAPPDATA%\PomogatorMAIN и добавляет ярлык в автозагрузку Windows.
5. В Помогаторе нажимайте «Получить план с MAIN». По запросу MAIN передаст исходный XLSX без изменений.

Путь к файлу: \\Main\data\План Меню и Бланки\ПЛАН ПРОИЗВОДСТВА С 17.08.2026.xlsx
Журнал: %LOCALAPPDATA%\PomogatorMAIN\agent.log
Проверка: CHECK_MAIN.cmd. При работающем фоновом модуле сообщит, что он уже запущен.

Нет расписания в 09:00. Файл читается ТОЛЬКО при запросе из Помогатора.
На этом этапе документы в iiko НЕ создаются. Начнём с проверки передачи файла.
